## ✏️ 내용 고치기

자주 바꾸는 내용은 각 파일 안의 데이터 목록에 모여 있습니다.

| 바꿀 내용 | 파일 | 위치 |
|---|---|---|
| 홈 문구·주제 성구 | `index.html` | `const COPY` |
| 지구본의 역대 개최지 | `index.html` | `const HOSTS` |
| 월별 일정·영성기획팀 프로그램 | `plan.html` | `const MONTHS` |
| WYD 십자가 순례 일정 | `plan.html` | `const CROSS` |
| 준비 시작일·본대회 날짜 | `plan.html` | `START`, `WYD` |
| 순례길 코스·순례지 | `pilgrim.html` | `const COURSES` |
| 프로그램 추가·수정 | `program.html` | `const PROGRAMS` — `from`/`to` 날짜로 지난·진행 중·예정 자동 분류, `img`가 있으면 포스터 카드 |
| 신청 열기·마감 | `join.html` | `const JOINS` — `status`를 `soon`/`open`/`closed`로, `url`에 신청서 주소 |
| 홀리마켓 부스 선점 현황 | `market.html` | `const BOOTHS` — 구역(`exp`·`snack`·`market`)에 신청 순서대로 `{team:"레지오", item:"수제 쿠키"}` 추가, 외부 신청은 `ext:true`, 기준일은 `UPDATED` |
| 홀리마켓 부스 승인 | 관리자 페이지 | 구글 폼 신청을 승인·반려하면 `/market` 선점 현황에 자동 반영 ([설치](tools/booth-admin/README.md)) |
| 홀리마켓 준비 일정 | `market.html` | `const STEPS` — 지난 단계는 흐리게, 다음 단계는 금색으로 자동 표시 |
| 숨겨 둔 참여 버튼 | 모든 페이지 | `[data-join]{display:none!important}` 한 줄 삭제 시 표시 |

### 새 소식을 올릴 때

1. 해당 페이지의 데이터 목록을 고칩니다.
2. `rss.xml` 맨 위에 `<item>`을 하나 추가합니다 (제목·링크·설명·날짜·고유 guid).
3. 페이지를 새로 만들었다면 `sitemap.xml`에 주소(한국어·영문 둘 다)를 추가하고, 각 페이지의 메뉴(`.mn nav`)에도 링크를 넣습니다.
4. 내부 링크는 깔끔한 주소(`/about`, `/en/about`)로 씁니다 — `.html`·`?v=` 캐시 번호는 붙이지 않습니다.

### 영문판 맞추기

`en/*.html`은 직접 고치지 않고 한국어 페이지에서 다시 만듭니다. 한국어 문구를 고쳤다면 [`tools/en-build/README.md`](tools/en-build/README.md) 순서대로 번역표(`tr/<page>.json`)를 채우고 `build.py`·`prerender.js`를 실행합니다.

## 🗂 구성

```
.
├── index.html        # 홈 — 지구본·두 손·유리 카드 히어로, 공식 앱 버튼
├── about.html        # 소개
├── plan.html         # 1년 일정
├── pilgrim.html      # 순례길
├── program.html      # 프로그램 (영적 순례 여정)
├── join.html         # 참여하기 (봉사자·순례길·홈스테이·홀리마켓 신청 카드)
├── rosary.html       # 묵주기도 10억 단 봉헌운동 (실시간 현황 + 실패 시 const STAT)
├── functions/api/rosary.js  # 교구 봉헌통계를 읽어 JSON으로 주는 Cloudflare Pages Function (/api/rosary)
├── functions/api/booths.js  # 홀리마켓 승인 부스(공개현황 CSV)를 JSON으로 주는 Function (/api/booths)
├── functions/api/request.js # 수정요청 접수를 구글 Apps Script(시트 저장·접수 메일)로 넘기는 Function (/api/request)
├── functions/api/inquiry.js # 문의서를 같은 Apps Script로 넘기는 Function (/api/inquiry)
├── tools/edit-requests/  # 수정요청 접수 스크립트·처리 기록 — 흐름은 안의 README
├── tools/en-build/    # 영문판 생성·언어 스위치·화면 테마 도구 (번역표 tr/*.json) — 사용법은 안의 README
├── en/               # 영문판 13쪽 (tools/en-build로 자동 생성, 직접 고치지 않음)
├── tools/booth-admin/  # 홀리마켓 부스 승인 관리자 페이지 (구글 Apps Script, 비공개) — 설치 방법은 안의 README
├── donate.html       # 후원금 모금 안내
├── contact.html      # 문의 · 수정 요청 (메뉴 전용)
├── request.html      # 수정요청서 (이름·세례명·연락처·단체명·내용 → /api/request → 구글 시트, 검색 제외)
├── inquiry.html      # 문의서 (→ /api/inquiry, 검색 제외)
├── homestay.html     # 홈스테이 세부 (본당 매뉴얼 2026.4 기준)
├── market.html       # 성탄 홀리마켓 세부
├── go.html           # 카카오톡 → 기본 브라우저 중계 (amsawyd.com/go#<주소>, 구글 스크립트·폼·amsawyd.com만 허용, 검색 제외)
├── prog-*.jpg        # 프로그램 포스터·현장 사진
├── fonts/            # 공식 앱 제목용 페이퍼로지 Bold (해당 글자만 서브셋, SIL OFL 1.1)
├── wyd-logo.svg      # WYD SEOUL 2027 공식 로고 (본당 매뉴얼 수록본에서 추출, 원본 색·비율 유지)
├── og.jpg            # 카카오톡·SNS 링크 미리보기 이미지
├── robots.txt        # 검색엔진 안내 (사이트맵 위치)
├── sitemap.xml       # 검색엔진용 페이지 목록
├── rss.xml           # 소식 피드 (새 소식은 맨 위에 item 추가)
├── bg*.png           # 배경 이미지 (휴대폰·태블릿·데스크톱)
├── hands.png         # 두 손 이미지
├── *-mask-*.svg      # 손 이미지 가장자리 마스크
└── docs/             # 준비 참고 문서 (본당 매뉴얼 요약 등)
```

빌드 과정이 없는 순수 HTML·CSS·JavaScript입니다(영문판만 `tools/en-build`로 미리 만들어 함께 올림). 파일을 고치고 `main`에 push하면 1분 안에 사이트에 반영됩니다.

## 🚀 배포

| 곳 | 주소 | 방식 |
|---|---|---|
| **공개 주소** | <https://amsawyd.com> | Cloudflare Pages 커스텀 도메인 (www 포함) |
| Cloudflare Pages | <https://amsa-wyd-2027.pages.dev> | `main` push 시 자동 배포 (빌드 명령 없음, 출력 `/`) |
| GitHub Pages | <https://gunhojin.github.io/amsa-wyd-2027/> | `main` 브랜치 루트 |

주보·QR·홍보물에는 **amsawyd.com**을 사용합니다.

`/api/rosary`(묵주기도 실시간 현황)는 Cloudflare Pages Functions로 동작하므로 amsawyd.com·pages.dev에서만 되고, GitHub Pages에서는 기준일 숫자로 표시됩니다. 응답은 30분 캐시합니다.

로컬에서 미리 보기:

```bash
python -m http.server 8000
# http://localhost:8000
```
