# 2027 서울 WYD 본당 매뉴얼 요약 (조직위원회, 2026년 4월 배포)

작성: Gunho · 원본 112쪽 PDF에서 본당 준비에 필요한 내용만 정리

## 기본 숫자
- 예상 참가자 최대 40만 명(숙박 35만 명), 서울대교구 220여 개 본당
- 본당마다 순례자 약 2천 명 숙소 지원: 홈스테이 약 500명 + 본당숙소·공동숙소 약 1,500명
- 참가 신청 2027년 상반기 완료 → 본당별 순례자 인원 2027년 7월 확정(8.3까지 변동 가능)
- 7월 확정 전까지 패키지·언어를 알 수 없으므로 짧게 4일, 길게 9일 맞이 준비
- 서울 모든 본당은 본대회 2~4일차(8.4 수~8.6 금) 교리교육 장소로 사용

## 본당위원회(P.O.C.) 조직
- 위원장 주임 신부 / 부위원장 부주임·보좌 신부 / 협력 수도자 전교 수녀 / 집행위원장 사목회장
- 사목협의회 각 분과 + 구역협의회가 임시 체제로 전환, 가장 먼저 청소년·청년 대표 선발과 WYD분과 구성
- WYD분과(청소년·청년분과장 겸임 가능): 순례자 환영·교류 프로그램, 본당 젊은이 본대회 인솔, 지구위원회(F.O.C.) 회의, 봉사자 교육
- 재정분과: 예산안 작성·집행·결산(세부 지침은 교구 관리국 추후 안내)

## 순례자 패키지(11종, 숙박 포함 6종)
- A1: 숙박 8.2 저녁~8.9 아침(8일), 숙소 조식 제공, 식사·교통은 충전식 선불 카드
- A1+: 8.1 저녁부터 또는 8.10 아침까지(9일)
- 숙박 일정은 홈스테이·본당숙소·공동숙소 모두 동일

## 홈스테이
- 기간: 2027.8.1(일)~8.9(월), 상황에 따라 연장 가능
- 호스트 자격: 본당 교적, 최근 3년 교무금·판공성사 이력, 성인 거주, 최소 2명 이상 수용(청소년 순례자 성인 인솔자 동반)
- 숙박 환경: 침대 불필요, 1인당 2m×1.5m(침낭+가방), 욕실·화장실 공동 사용 가능, 본당·행사장 도보·대중교통 접근(어려우면 호스트 이동 지원)
- 조식: 토스트·시리얼·우유 등 간단히, 어려우면 본당 조식 합류(사전 협의)
- 선정: 신청서·명단 검토 후 본당 신부님 최종 선정 → 사전 모임에서 교육
- 배정: 가정 희망(인원·성별) 반영, 혼숙 금지, 같은 국가·언어권 우선, 미성년·여성·도움 필요 순례자 별도 기준
- 일정(A1): 8.1~2 가정으로 인솔 → 8.3~6 조식 후 본당 이동 → 8.7 밤샘기도(외박) → 8.8 귀가 → 8.9 환송
- 신청서 양식: 부록 103쪽(가족 대표 인적 사항, 가족 구성원, 주거 형태, 반려동물, 언어, 원하는 성별, 인원수, 제공 공간)

## 본당 봉사자
- 젊은이 봉사자가 주축, 역할별 모집(안내, 숙소 관리, 식사 지원, 통역, 행정)
- 조직위 사목본부 교육분과 직무 교육 자료, 청소년국 젊은이 봉사자 교육(공문 예정)
- 조끼·어깨띠·명찰로 식별, 숙소에 외출 시간 동안 최소 1명 상주

## 본대회 기간 본당 운영
- 8.1~2 입소: 입소·숙소 안내 → 순례자 등록 → 키트 배부 → 환영 세리머니·오리엔테이션 → 식사
- 소통 담당 봉사자 배정(카톡·인스타 DM·왓츠앱 + 번역 앱)
- 숙소 시간표 예시: 6시~ 외출 가능, 9~18시 출입 불가(정비), 23시 문 잠금, 24~6시 이동 금지
- 조식은 업체가 본당·공동숙소로 배송, 배식 동선·시간대 분리
- 8.7~8 밤샘기도·폐막미사: 봉사자도 참석하므로 숙소 보안 방안 필요, 환자는 거점 본당
- 미사: 순례자 그룹 미사 공간 지원, 본당 평일 미사 합동 제안 가능

## 지구위원회 관련
- WYD 십자가·성화: 2026.1.21 원주교구 시작, 2027년 5월 말 서울 귀환, 지구별 순례 예식
- 지구별 월 1회 WYD 지향 영어 미사(폐막·개막미사 주님의 기도는 라틴어 성가)
