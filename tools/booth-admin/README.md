# 홀리마켓 부스 승인 페이지 (관리자 전용)

구글 폼 응답 시트에 붙이는 Apps Script 웹 앱입니다. amsawyd.com에는 올라가지 않고, **응답 시트 편집 권한이 있는 Google 계정만** 열 수 있습니다.

```
구글 폼 ──▶ 응답 시트 ──(승인/반려)── 관리자 페이지 (Apps Script)
                │
                └─ '공개현황' 탭 (승인된 구역·단체·아이템만) ──웹에 게시 CSV──▶ /api/booths ──▶ amsawyd.com/market
```

## 기능

- 신청을 제출 순서(선착순)대로 번호를 매겨 표시, 상태(대기·승인·반려)·구역별로 거르기
- 구역별 자리 수(체험 4 · 식음료 6 · 판매 10) 집계, 마감되면 승인 버튼 잠금
- 같은 아이템 최대 2부스 검사 — 1순위가 찼으면 2순위가 자동 선택, 직접 입력도 가능
- 간식존은 메뉴 6가지(`SNACK_MENUS`) 중 선택, 메뉴마다 1부스 — 폼에 선택 섹션을 넣는 `updateFormSnackMenu`를 한 번 실행
- 반려는 사유 필수, 승인 취소·대기로 되돌리기 가능
- 처리자·처리일시가 응답 시트 오른쪽 열에 기록
- 폼 밖에서 확정한 부스(`RESERVED`)도 자리 수·아이템 계산에 포함

## 설치 (처음 한 번)

1. **폼 응답을 시트에 연결** — 구글 폼 편집 화면 › 응답 탭 › `Sheets에 연결` › 새 스프레드시트
2. **스크립트 붙여넣기** — 그 스프레드시트 › 확장 프로그램 › Apps Script
   - `Code.gs` 내용을 그대로 붙여넣기
   - 파일 `+` › HTML › 이름 `Admin` › `Admin.html` 내용 붙여넣기 › 저장
3. **준비 실행** — 함수 목록에서 `setup` 선택 › ▶ 실행 › 권한 허용
   (응답 시트에 `처리상태…처리일시` 열, `공개현황` 탭이 생깁니다)
4. **웹 앱 배포** — 배포 › 새 배포 › 유형 `웹 앱`
   - 실행 계정: **웹 앱에 액세스하는 사용자**
   - 액세스 권한: **Google 계정이 있는 모든 사용자**
   - 배포 › 나온 웹 앱 URL이 관리자 페이지입니다
5. **공개 현황 연결** — 스프레드시트 › 파일 › 공유 › `웹에 게시` › `공개현황` 탭 · `쉼표로 구분된 값(.csv)` › 게시
   - 나온 CSV 주소를 `functions/api/booths.js`의 `CSV_URL`에 넣거나, Cloudflare Pages 환경변수 `BOOTHS_CSV`로 지정

## 권한 관리

- 처리할 사람에게 **스프레드시트 편집 권한**만 공유하면 됩니다. 편집 권한이 없으면 페이지가 열리지 않습니다.
- 특정 계정만 허용하려면 `Code.gs`의 `ADMINS`에 이메일을 적습니다.
- `공개현황` 탭에는 구역·단체명·연합 단체·배정 아이템·순번만 들어갑니다(단체장·연락처 제외).

## 설정 바꾸기 (`Code.gs` 위쪽)

| 항목 | 기본값 |
|---|---|
| `CAPS` 구역별 부스 수 | 체험 4 · 식음료 6 · 판매 10 |
| `MAX_SAME_ITEM` 같은 아이템 최대 | 2 |
| `RESERVED` 폼 밖 확정 부스 | 없음 |
| `ADMINS` 처리 허용 계정 | 비움 = 시트 편집자 누구나 |

코드를 고친 뒤에는 배포 › 배포 관리 › 수정 › 버전 `새 버전`으로 다시 배포해야 반영됩니다.
